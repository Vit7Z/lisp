1. Отключить Инфоцентр.
Закройте AutoCAD.
Нажмите WINDOWS-R на клавиатуре, чтобы вызвать окно «Выполнить», введите REGEDIT и нажмите ОК.
HKEY_CURRENT_USER\Software\Autodesk\AutoCAD\Rxx.x\ACAD-xxxx:40x\InfoCenter
Этот путь уникален для каждой версии AutoCAD, которую можно узнать, выбрав ACAD-xxxx, а затем посмотрев на ключи на правой панели редактора реестра. 
В одном из ключей будет отображаться путь установки для соответствующей версии AutoCAD. Номер 40x обозначает язык версии AutoCAD.
На правой панели окна дважды щелкните InfoCenterOn, введите значение 0 (ноль) и нажмите ОК.


2. Отключить страницу "Начало"
Введите STARTMODE в командной строке AutoCAD.
Введите 0 (ноль), чтобы отключить вкладку «Начало» или 1, чтобы включить ее.

3. SDI - переменная, которая отвечает за просмотр чертежей в каждом новом окне или в одном окне.

4. Двойной клик для редактирования одиночных примитивов (TEXT и MTEXT) можно настроить через редактирование двойного клика в настройках автокада.
