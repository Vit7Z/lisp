read-file-for-dialog-box-01 (name-file num-flds) - чтение файла по строкам, разбиение строк по знаку \ и 
формирование списков для menu, dscr, полей данных. Пример списка:
1****\2****\3****
4****\5****\6****
Алгоритм списка. 
Список 1: 1**** + 4****
Список 2: 2**** + 5****
Список 3: 3**** + 3****
Извлечение элементов list-02 list-01-read-file

Извлечение элементов list-02 (cdr (nth 0 list-902-read-file))

/////////////////////////////////////////////////
read-file-01-general-for-dialog-box-01 (name-file num-flds) - чтение файла 01-general (формирования списка в первом левом окне диалога 
и фомирование списка файлов данных) по строкам, разбиение строк по знаку \ и формирование списков. 
1****\2***\ - разбивается на список. список формируется по полю 1**** вертикально (первый член строки является первым элементом списка, п
ервый элемент строки 2 является элементом 2 списка).
Извлечение элементов list-02 list-01-read-file
